버튼만들기 레이아웃 예시

📘 버튼 레이아웃 설명

🏗️ 구조 설계 방법

일반적으로는 그룹을 나누어 래퍼(div) 를 두는 방식이 가장 깔끔합니다.

<div class="button-area"> <!-- 위쪽 2개 버튼 그룹 --> <div class="button-row"> <button>버튼1</button> <button>버튼2</button> </div> <!-- 아래쪽 단독 버튼 --> <div class="button-row single"> <button>버튼3</button> </div> </div>

🎨 CSS (반응형 포함)

Flexbox를 쓰면 간단하게 정렬할 수 있습니다.

.button-area { display: flex; flex-direction: column; /* 세로로 쌓기 */ gap: 10px; /* 그룹 간격 */ } .button-row { display: flex; justify-content: space-between; /* 버튼 2개를 양쪽으로 */ } .button-row.single { justify-content: center; /* 단독 버튼은 가운데 */ }

📱 반응형 고려

작은 화면에서는 버튼 2개도 세로로 쌓고 싶을 수 있죠. 그럴 땐 미디어쿼리를 추가합니다.

@media (max-width: 600px) { .button-row { flex-direction: column; /* 버튼 세로 배치 */ } }
✅ 정리
  • 그룹화(div 묶기): 위쪽 2개 버튼 / 아래쪽 버튼
  • Flexbox 사용: 가로 / 가운데 정렬
  • 미디어쿼리로 모바일 대응
